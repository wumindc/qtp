# Support

QTP is an early-stage open-source project. The fastest way to get help is to open a focused GitHub issue with enough context for someone else to reproduce the problem.

## Where to Ask

- **Bug report**: use the Bug Report issue template.
- **Feature idea**: use the Feature Request issue template.
- **Roadmap discussion**: reference [ROADMAP.md](./ROADMAP.md) and explain which stage your idea affects.
- **Security concern**: follow [SECURITY.md](./SECURITY.md).

## Good Support Requests Include

- What you were trying to do.
- What happened instead.
- Your OS, Node.js version, pnpm version, and current commit.
- The exact command or page URL.
- Logs, screenshots, or a short recording when useful.

## Project Boundaries

QTP focuses on AI application regression testing: multi-turn Golden Cases, baseline vs candidate comparison, failure diagnosis, and review workflows. General LLM benchmark requests, unrelated model leaderboard work, and full defect-management workflows are outside the early scope.
