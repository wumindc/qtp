重写后保留

  • 业务功能、现有后端接口 `.do`、上下文路径 `/ai-quality-platform`。
  • Next App Router、React 19、lucide 图标、monorepo 工作区。
  • 已有功能页的业务语义：应用、用例、模型、健康、执行、报告。

重写后替换

  • 现有手写 CSS 工具类和 console/app-detail 样式体系。
  • 页面内直接 fetch 的数据读取方式。
  • 页面内手写表格、表单、弹窗、状态标签和重复布局。

建议迁移顺序

先做一页 POC：模型中心或 AI 应用目录。它们能同时验证 HeroUI 表单、弹窗、抽屉、表格、筛选、服务端请求和复杂状态。POC 通过后，再按“基础布局 → 设计系统 → 数据层 → 页面重写 → 回归测试”的节奏推进。
