# 应用评估配置实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为应用工作区新增「评估配置」菜单，配置评估模型和应用级裁判提示词，并在执行计划时用 LLM Judge 对每条真实调用结果做评估。

**Architecture:** 评估配置是应用级配置，由 `quality-business-service` 维护并持久化到新表 `app_evaluation_config`。`quality-execution-service` 启动执行前强校验评估配置、评估模型和供应商均可用；执行过程中逐条调用被测应用接口，再用配置的模型和提示词评估该条结果。若执行前配置或模型不可用，执行批次不创建；若执行中某条评估调用失败，仅该条结果标记失败并落库失败原因。

**Tech Stack:** Prisma/MySQL, NestJS services, Next.js App Router, React 19, Tailwind, Vitest.
