# UI 表单规范

## 目标

控制台内所有新增、编辑、配置类表单都必须使用统一的字段组件和校验展示，避免浏览器原生校验气泡、字段错位、只读状态不清晰等问题。

## 规则

- 表单必须设置 `noValidate`，禁止浏览器原生气泡校验。
- 必填、错误、提示、只读状态必须通过统一字段组件展示。
- 字段错误文案显示在控件下方，错误区保留固定最小高度，校验前后同一行字段不得上下错位。
- 只读字段必须有明显视觉状态：浅灰背景、禁用光标或说明文案。
- `TextInput`、`TextArea`、`ConsoleSelect` 必须支持 `label`、`required`、`error`、`hint`。
- 页面业务代码负责提交前校验，并将错误写入组件 `error` 属性。
- 不允许在新代码中直接使用裸 `input/select/textarea` 搭建弹窗表单，除非该控件本身不是表单字段。

## 推荐提交校验流程

1. `event.preventDefault()`。
2. 读取表单状态，构建错误对象。
3. 如果错误对象非空，写入错误状态并停止提交。
4. 成功提交或用户输入后清理对应字段错误。

## 视觉验收

- 空表单提交后没有浏览器原生气泡。
- 左右两列字段仍然顶部对齐。
- 必填星号稳定显示。
- 错误态边框、错误文案和 hint 不互相挤压。
