# 真实执行闭环实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development for each behavior change. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将执行计划、执行历史、历史详情从“DB 列表 + 伪执行结果”升级为真实按计划筛选用例、真实调用应用协议、真实保存并展示执行结果。

**Architecture:** 执行服务成为真实执行编排入口：读取 `eval_plan.caseFilterJson`、`ai_app.adapterConfig` 和 `eval_case`，按计划过滤用例后逐条调用应用协议，并把请求、响应、耗时、答案、评分、失败原因写入 `eval_run` / `eval_result`。前端继续通过网关调用 plan/execution 服务，历史详情只展示后端返回的真实字段。

**Tech Stack:** NestJS service/controller, Prisma MariaDB runtime client, Next.js client components, Vitest, Testing Library, Tailwind/Radix UI。
