# 服务架构收敛实施计划

> 本计划承接 `docs/20260527-002-服务架构收敛设计.md`，用于研发、验收和后续追踪。

## 目标

把当前 8 个后端业务服务收敛为：

- `quality-gateway`
- `quality-platform-service`
- `quality-execution-service`
- `packages/ai-model-adapter`

同时保持前端公开 API 路径兼容，不把架构调整扩散成前端接口重写。

## 完成标准

- 运行时后端服务数量收敛到 gateway、platform、execution。
- 公开 API 段保持兼容。
- 旧业务服务目录不再作为独立 workspace 应用存在。
- AI 模型调用标准进入共享 package。
- 单元测试、类型检查、健康检查和浏览器验收都通过。
